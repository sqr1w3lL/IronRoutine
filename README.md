# IRON ROUTINE — личный дневник домашних тренировок

Android-приложение (Kotlin, Jetpack Compose, Material 3, Room, MVVM, Coroutines/Flow, Navigation Compose).
Работает полностью офлайн, без регистрации. Все данные хранятся на устройстве.

## Сборка и запуск

1. Установи **Android Studio** (актуальная стабильная версия) — JDK 17 идёт в комплекте.
2. `File → Open` и выбери папку `IronRoutine`.
3. Дождись `Gradle Sync`. Студия сама скачает Gradle 8.9 (см. `gradle/wrapper/gradle-wrapper.properties`) и зависимости.
   Если в проекте нет `gradle-wrapper.jar`, студия использует wrapper-настройки сама; из терминала можно выполнить `gradle wrapper --gradle-version 8.9`.
4. Подключи телефон (Android 8.0+, API 26) с включённой отладкой по USB или создай эмулятор.
5. Нажми **Run ▶**. APK для установки: `Build → Build Bundle(s) / APK(s) → Build APK(s)`.

Версии зафиксированы на проверенном наборе: AGP 8.7.3, Kotlin 2.0.21, KSP 2.0.21-1.0.28, Compose BOM 2024.12.01, Room 2.6.1.
Они лежат в одном месте — `gradle/libs.versions.toml`. Если студия предложит обновить AGP — используй *AGP Upgrade Assistant*
(AGP 9 требует миграции build-файлов, это делает ассистент).

## Как работает увеличение нагрузки (`domain/Progression.kt`)

Решение принимается только по **реальным результатам последней завершённой такой же тренировки** (тот же день программы).
Наступление новой недели и пропуски на нагрузку не влияют, «компенсации» нет.

| Ситуация | Рекомендация |
|---|---|
| Первая тренировка | Подсказка, как выбрать вес |
| План не выполнен (мало подходов или повторений ниже нижней границы) | Нагрузку не повышаем |
| Техника была отмечена как «нечистая» | Нагрузку не повышаем |
| Плохое самочувствие или заметное падение результата | Сохранить нагрузку |
| Так два занятия подряд | Предложить снизить (вес или цель по повторениям) |
| Перерыв 14 дней и больше | Вернуться без прибавки |
| Все подходы на верхней границе диапазона, техника чистая | Предложить **вес** (штанга; гантели — если в настройках они разборные) |
| То же, но вес увеличить нельзя (гантели 5 кг, свой вес) | Предложить **больше повторений** (шаг 2, для планки 5 с, максимум три шага), потом — усложнить вариант |
| Выполнено, но до верхней границы ещё есть запас | Цель: +1 повторение в слабых подходах |

Вес и количество подходов одновременно не увеличиваются (подходы вообще не растут автоматически).
Рекомендация показывается карточкой с кнопками **«Принять»** / **«Оставить как есть»**.

## Как изменить программу и добавить упражнение

**Быстро, без кода:** `Настройки → Параметры тренировок → Изменить` — подходы, диапазон повторений, отдых.

**В коде (`data/program/ProgramData.kt`):**

1. Добавь `ExerciseDef(...)` в список `list` (id, название, мышцы, оборудование, `usesWeight`, `measure`, краткая подсказка).
2. Добавь `PlannedExercise("id", подходы, повт_от, повт_до, отдых_от, отдых_до)` в нужный день внутри `baseDays`.
3. Добавь инструкцию в `data/program/Guides.kt` (карта `map`).
4. Добавь позу в `ui/components/Illustrations.kt` → `PoseData.poses` (две позы: начало и конец; формат описан в комментарии над объектом).
   Без позы будет показана пустая заглушка, поэтому поза обязательна.
5. Чтобы поменять дни недели — поле `weekday` у `WorkoutDay`. Новый день добавляется как ещё один `WorkoutDay`.

Если добавляешь/переименовываешь упражнение, старые записи истории остаются в базе под прежним id.

## Данные и резервная копия

* Room: тренировки, подходы, результаты, замеры, прогрессия, изменения плана. Подходы пишутся в базу сразу при каждом изменении,
  поэтому закрытие приложения во время тренировки ничего не теряет — на главной появится «Продолжить тренировку».
* `Настройки → Резервная копия` — сохранение/восстановление всего в один `.json`.

## Допущения

* В задании не везде указан отдых — выставлено: подтягивания 90–120 с, одиночные сгибания/тяги 60–90 с, сгибания кистей 45–60 с, планка 45–60 с.
* Подтягивания: диапазон 1–10 «качественных» повторений (макс. качество, не до отказа). Есть варианты «Негативные» и «С помощью».
* Выпады назад — со своим весом (вес не записывается). Чтобы вести вес гантелей, поставь `usesWeight = true` и `equipment = DUMBBELL`.
* Вес штанги «уточняется»: по умолчанию 20 кг, меняется в настройках. Шаг прибавки штанги — 2,5 кг.
* Гантели считаются неразборными (5 кг), поэтому прогресс в упражнениях с ними идёт через повторения.
* Номер недели считается от даты старта программы (16.11.2026) до даты окончания (31.12.2026). После окончания тренировки продолжаются.
